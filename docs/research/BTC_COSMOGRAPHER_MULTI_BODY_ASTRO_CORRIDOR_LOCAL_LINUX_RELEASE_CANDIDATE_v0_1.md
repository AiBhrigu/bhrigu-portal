## Salience contract

Windows are ranked from accepted public astronomy evidence using explicit, deterministic features:

1. slow-cycle body scale;
2. minimum daily orb;
3. window duration;
4. exact-event clustering;
5. station and ingress overlap.

The rank is a BHRIGU research ordering. It is not a claim that the configuration causes BTC price movement.

## Answer order

Internal analysis is slow-to-fast. Public language is nearest-to-longest:

1. chronological windows;
2. stations and ingresses;
3. slow carrier context;
4. ranking method;
5. interpretation boundary.
